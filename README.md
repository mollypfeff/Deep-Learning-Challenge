# Deep-Learning-Challenge
This repository contains my submission for the Module 21 Challenge due on 3/25. All of the work present has been created by myself, Molly Pfefferkorn. My instructor, Dr. Carl Arrington, provided troubleshooting feedback during the designated office hours of this class. Data for this dataset was generated by edX Boot Camps LLC, and is intended for educational purposes only.
----

In this challenge, I built and optimized a deep learning model to help the nonprofit Alphabet Soup predict which funding applicants are most likely to succeed. The goal was to develop a binary classifier using historical data from over 34,000 funded organizations, leveraging machine learning techniques to assist in future funding decisions. After creating a dedicated GitHub repository called deep-learning-challenge, I began by preprocessing the charity_data.csv dataset in Google Colab. I identified the target variable (IS_SUCCESSFUL) and selected the appropriate feature variables, dropping non-informative columns like EIN and NAME. I analyzed categorical features for high cardinality, grouped rare values into a new category called "Other," and used pd.get_dummies() to encode the data. Finally, I split the data into training and testing sets and scaled the features using StandardScaler.

In the next phase, I designed a neural network using TensorFlow and Keras, selecting an appropriate number of input features, hidden layers, and activation functions. The model was compiled and trained, and its performance was evaluated using loss and accuracy metrics on the test set. I also implemented a callback to save the model’s weights during training and exported the trained model to an HDF5 file named AlphabetSoupCharity.h5.

To improve accuracy beyond 75%, I created a second Colab notebook and applied multiple optimization techniques. These included adjusting the structure of the neural network (e.g., adding layers and neurons), modifying activation functions, and experimenting with the number of epochs. The optimized model was saved as AlphabetSoupCharity_Optimization.h5.

Lastly, I documented the entire process in a well-structured report, clearly explaining the purpose of the analysis, preprocessing steps, model architecture, evaluation results, and optimization strategies. I reflected on the model’s performance and suggested how other machine learning methods, such as random forests or gradient boosting, could be used as alternatives to potentially improve classification accuracy.
